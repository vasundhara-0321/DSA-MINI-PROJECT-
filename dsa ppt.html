Section 01 · Problem Space

Problem Identification & Objectives

Problem Statement
FIFO processing delays critical shipments.
Traditional FIFO order processing creates major delivery delays because high-priority express shipments wait behind low-priority standard orders, leading to missed SLAs and dissatisfied customers.
Core Problem
Dynamic routing + audit trail.
How can a warehouse dynamically route high-priority orders first while preserving a complete dispatch history for audit trails and regulatory compliance?

Section 04 · Algorithms

Core Algorithm & Logic

Insert Algorithm · Up-Heapify

O(log n)
1 · Check heapSize < MAX
2 · Insert at heap[heapSize]
3 · Swap with parent (i-1)/2 → while child priority > parent
4 · Continue until heap-order restored

Dispatch Algorithm · Down-Heapify

O(log n) + O(1)
1 · Check heapSize > 0
2 · Extract heap[0] → the highest priority
3 · Move last element to root
4 · Compare children (2i+1, 2i+2) → swap down
5 · Push to stack [++top] for audit log

Program Implementation & Complexity Analysis

Language
C · <stdio.h> <stdlib.h> <string.h>
Implementation leverages the standard C library only — no external dependencies. Each function is isolated, testable, and wraps heap or stack primitives with explicit bounds checks.
Function Responsibility Complexity
getPriority() Priority tier mapping (Express / Urgent / Normal) O(1)
swap() Struct address exchange between two Order records O(1)
insertOrder() Up-heapify algorithm — inserts new order into Max Heap O(log n)
dispatchOrder() Root extraction & down-heapify + stack push for audit O(log n) + O(1)
displayPendingOrders() Sequential heap array scan of all queued orders O(n)
displayDispatchedOrders() LIFO stack array scan of dispatched history log O(n)
O(1)

Tree-height bounded heapify operations — predictable under heavy load.

Section 06 · Safety

Advanced Exception Handling & Code Safety

01
Heap Overflow Guard
Prevents writing past array bounds when the heap is full — critical for memory safety in fixed-buffer dispatchers.
if (heapSize >= MAX) { // reject insertion }
02
Queue Underflow Guard
Intercepts deletion calls on an empty heap, preventing undefined root extraction behaviour.
if (heapSize == 0) { // abort dispatch }
03
Stack Boundary Checks
Guards push operations against overflow and display against underflow on the audit stack.
if (top < MAX - 1) { push(); }
if (top == -1) { // stack empty }
04
Input Validation
Traps out-of-range priority menu choices before they pollute the heap with invalid tier values.
if (order.priority == 0) { // reject, re-prompt }
